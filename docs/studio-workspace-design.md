# Shutter studio workspace

Approved direction: Dom's September 10 request for a beautiful, understandable studio with directing, a connected media canvas, and straightforward editing. Continue inline under the existing authorization. No paid generation in this milestone.

## Product law

The film is the centre of the room. Quiet controls frame actual footage; complexity appears where a creative decision needs it. A single production moves between Direct, Canvas and Edit. These views use the existing shots, reference bindings, takes and saved timeline.

Direct presents the current take, a compact direction composer, reference previews and a shot strip. Saving direction edits the real shot. Advanced shot settings retain the existing generation, continuity, estimate and render controls. There is no simulated chat agent.

Canvas is a working reference graph for the selected shot. Image, video and audio nodes connect to the shot using supported input roles. Connections update the same production fields consumed by H3 preparation. A selected saved take and the edit are downstream navigation destinations, explicitly labelled as existing footage rather than regenerated results. Node placement persists independently of production revision. Drag connections have a keyboard-accessible form equivalent. Import uses the existing local asset store. Model changes and render submission remain explicit in shot settings.

Edit retains the verified main/coverage timeline, source trims, undo/redo and exact local export. This pass improves presentation; it does not claim a real-time compositor or an audio mixer.

## Visual system

Palette: coal #151716 (workspace), graphite #1d201e (surfaces), seam #343a36 (borders), chalk #edf0e9 (primary text), silver #a7b0a9 (secondary text), sage #bfd5ba (creative action and selected state). Footage supplies the rich colour. No gradients behind utility panels, no fabricated waveforms, no floating decorative cards.

Typography: Segoe UI Variable / Segoe UI for calm interface text; Bahnschrift / Segoe UI for compact display headings and wordmark. Clear sentence case, tabular figures for time. Native installed fonts keep this pass dependency-free.

Desktop: compact left navigation, project bar, large viewer and a narrow direction panel. Canvas uses a scrollable, zoomable board. Edit makes the viewer and tracks prominent. At narrow widths navigation becomes a short top bar, secondary tools collapse into a menu, panels stack, and the canvas remains independently scrollable. No page-wide horizontal overflow. Visible focus, semantic labels, reduced-motion support.

## Acceptance

1. Direct, Canvas and Edit open and retain their view after reload; secondary tools remain reachable.
2. Direction saves through the existing production revision check; footage and selected takes are preserved.
3. Connecting an asset changes the next prepared H3 snapshot, creates no render job, rejects invalid roles/media and stale revisions, and leaves existing render snapshots immutable.
4. Node positions survive reopening. Invalid positions and stale layout saves leave state intact.
5. Rendered browser checks at desktop and narrow widths cover navigation, canvas manipulation, direction editing and timeline access. Existing timeline export tests remain green.
6. No generation charge; budget and original study footage remain intact.
