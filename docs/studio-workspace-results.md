# Studio workspace result

September 10, 2026. Local, on codex/shared-scene-timeline. No publication or paid generation.

Shutter now opens into three primary views: Direct, Canvas and Edit. The graphite/sage studio puts actual footage in the centre, uses compact typography and keeps Moment and production libraries accessible. The earlier detailed film screen remains available as Shot settings.

Direct saves action and camera through the existing production revision checks. This is a working direction composer, not an embedded Pixel conversation. Canvas projects the real H3 reference bindings into movable image/video/audio nodes, direction, a saved take and the current cut. A wire drag or the labelled connection form changes the inputs for the next take. Cast/world bindings are inherited from their existing records. Saved takes retain their own snapshots. Node placement is persisted independently and included in the production export.

Edit retains the previously verified timeline engine and now has real footage thumbnails, consistent shot names and a denser workspace showing preview, coverage, main performance and source audio together. On small screens the tracks scroll within their own area instead of compressing all clips into unreadable slivers.

## What this milestone does not establish

The canvas is a reference graph for a selected shot. It is not yet a general workflow executor with arbitrary compositing, text processors, masks or render-everything operations. Text is represented by the shot direction. Canvas placement does not change scene time; the Edit timeline owns time. A line to a saved take shows its historical relationship, not a claim that new references regenerated that take.

Preview still plays a locally exported exact cut. There is no real-time compositor, separate music/voice mixer, general object editor or in-app LLM conversation in this pass. Scene-state scheduling and synchronized alternate-angle generation still need validation. Existing Moment, Stage and review capabilities remain available; this redesign does not certify every older room as product complete.
